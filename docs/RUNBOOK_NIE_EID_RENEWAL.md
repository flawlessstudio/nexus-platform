# Runbook: NIE / eID / Renewal

This runbook outlines legal-first procedures for:
- Monitoring NIE appointment windows (no automation, read-only checks)
- eID (Cl@ve / FNMT) guidance and user education
- Renewal reminders and timelines (D-90/60/30/15/7)

Escalation: if anomalies detected (site down, rate-limit), pause checks and notify maintainers.
