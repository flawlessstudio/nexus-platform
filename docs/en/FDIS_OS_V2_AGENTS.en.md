# FDIS OS v2 · PureMind  
## Agents (EN)

## 1. Agent families

- Ingest Agents  
- Vision Agents  
- Semantic Agents  
- Processing Agents  
- Validation & Security Agents  
- Export Agents  
- Orchestration Agent  

## 2. Key examples

- **FS_01 · Ingest Agent**  
  Classifies the document and defines the initial pipeline.

- **FS_07 · OCR Agent**  
  Extracts text from printed documents.

- **FS_12 · Handwriting Agent**  
  Recognizes handwriting and returns text with confidence scores.

- **FS_13 · Diagram Agent**  
  Interprets diagrams and schematics into a graph structure.

- **FS_14 · Restoration Agent**  
  Fixes noisy, shadowed or skewed images.

- **FS_02 · Structure Agent**  
  Rebuilds logical structure: headings, sections, paragraphs, lists.

- **FS_10 · Semantic Refinement Agent**  
  Refines text and normalizes formats.

- **FS_11 · Table Agent**  
  Reconstructs complex tables, even without visible borders.

- **FS_20 · Security Agent**  
  Searches for signs of visual manipulation.

- **FS_21 · Consistency Agent**  
  Checks totals and numeric consistency.

- **FS_24 · Deep QA Agent**  
  Applies deep reasoning on the final document.

- **FS_09 · Export Agent**  
  Produces Excel, Word, JSON, GraphML and HTML.

- **OS_Controller**  
  Orchestrates the whole system.
