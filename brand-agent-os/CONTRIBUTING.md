# Contributing

1. Fork the repo and create a feature branch.
2. Follow the directory scopes documented in `docs/overview.md` and `docs/workflows-guide.md`.
3. Validate JSON/YAML with `ops/scripts/validate-all.sh` before opening a PR.
4. Include context in PR descriptions (brand, system, campaign, or agent touched).
5. Keep `brand.json`, `tokens.json`, and core specs in sync when updating a brand.
