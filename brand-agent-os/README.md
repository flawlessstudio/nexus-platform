# Brand + Agent OS

A studio-grade monorepo that hosts brand systems, shared tooling, agent prompts, and campaign archives for Flawless Studio's AI-first workflow.

## Structure

- `brands/` – per-brand "Brand OS" packages that hold positioning, identity, editorial rules, templates, assets, and knowledge.
- `systems/` – global, reusable design, editorial, marketing, and taxonomy systems that power all brands.
- `agents/` – specifications, prompts, tools, and orchestrated workflows for the AI workforce.
- `campaigns/` – campaign briefs, strategies, content, and performance histories scoped per brand.
- `assets/` – shared studio-wide assets (mockups, icon libraries, UI kits, textures, stock references).
- `ops/` – schemas, validation scripts, CI, and linting to keep the repo production-ready.
- `docs/` – human-facing playbooks and onboarding docs that explain how to use the OS.

Refer to `docs/overview.md` for the full operating model and best practices.
